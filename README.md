# 📁 Projects

## 🎰 Casino Gaming Analytics

**SQL Server | SQL | Power BI | DAX**

An end-to-end analytics project based on a simulated casino environment, combining my professional gaming industry experience with data analytics.

The project analyzes:

- Casino performance and gaming revenue
- Games and table performance
- Player and VIP behaviour
- Player retention and cohort analysis
- Deposits, withdrawals and cash flow
- Operational activity and peak hours

The Power BI report contains five analytical pages supported by a relational data model, SQL transformations and DAX measures.
